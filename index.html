AIは、学びの何を変えて、何を変えないのか｜おみやげページ

新宿区立柏木小学校 校内研修（2026年10月1日）参加者用ページ／前多昌顕

このページがあるので、メモは取らなくて大丈夫です

今日の講演の要点と、午前の3つの授業の手順・指示文をまとめました。指示文はコピーボタンでそのまま使えます。授業で使っていただいて構いません。

まず、今日の2行

AIは「作る」を変えます。「選ぶ・確かめる・感じる」は変えません。
だから、AIを使ったあとの子どもには「選んだ理由」が残っていてほしいと考えています。

「AIを使うと、子どもが考えなくなる」は、半分は当たっています。分かれ目は、道具ではなく授業の設計にあります。

境界線に、名前をつける

  • 認知オフローディング：作業を外に置いて、頭のリソースを空けること。メモ・電卓・辞書・検索と同じ「渡す」行為です。それ自体は良くも悪くもありません。
  • 認知アウトソーシング：「渡す」が行き過ぎて、判断や思考そのものまで手放してしまうこと。批判されているのは、こちらです。
  • スキャフォールディング（足場）：渡した先に「考える場面」を用意しておく設計。補助輪は、いつか外します。
足場があればオフローディング。足場がなければアウトソーシング。

同じAIでも、答えを言うAIで練習した高校生は、AIを取り上げた本番で成績が下がりました。ヒントだけを返すAIで練習した高校生は、下がりませんでした。違いは「答えを言うか、言わないか」だけです（Bastaniほか、2024）。

AIを使うから、考えなくなったのではありません。もともと考えていなかったことが、見えやすくなっただけです。

足場は、この3つ

  • ものさし：何を良しとするかを決めるのは人です。AIは、そのものさしに照らして助言するだけ。
  • 本物の体験：顕微鏡をのぞいた「うわっ、動いてる！」に、AIは勝てません。体験はリアル、作業はデジタル。
  • 「なぜそれにしたの？」を一言挟む：AIに答えを出させたら、そのまま丸をつけない。理由を聞く一手間です。

午前の授業①　3年 図画工作「ねんどのなかまに、色とばしょをあげよう」

マジック生成で粘土の作品をつくる → 見せ合う → 背景除去 → ペンで色をぬる（透明度を下げて、粘土のでこぼこを残す）→ 素材から背景を選ぶ → 時間があれば、お話を録音。

マジック生成に貼る（子ども用）
油ねんどで作った、かんたんな さかな の写真。色は ねんど色の 1色だけ。手でこねた あとが のこっている。カラフルに しない。白い つくえの 上に おいてある。
変えるのは「さかな」の1語だけ。「カラフルにしない」「1色だけ」は変えません。アニメやゲームのキャラクターの名前は入れないよう、先に伝えます。

午前の授業②　5年 国語「秋を十七音で」

ものさしを配る → 最初の一句は自分で（AIに触らない）→ AIに助言をもらう（読むだけ）→ AIが作った3句をものさしで評価して話し合う → 評価した目で自分の句を見直す → 直した・直さなかった理由を録画で説明。

ものさし（A よくできている／B できている／C もう少し）
1　音数とリズム（五・七・五。字余り・字足らずは、あえてならOK）
2　季語（季節が伝わる言葉がひとつ。季重なりはおおらかに）
3　表現の工夫（比喩・反復・言葉の順序・漢字と仮名の使い分け）
自分の俳句への助言（子ども用）
小学生が作った俳句です。次のルーブリックに照らして、良いところを一つ、もっと良くなる提案を二つ、小学生に分かる言葉で書いてください。直した句は示さないでください。
この教材では、字余りや字足らずも許し、季重なりもおおらかに扱います。決まりを機械的に指摘しないでください。
ルーブリック
1　音数とリズム
2　季語
3　表現の工夫（比喩・反復・言葉の順序・漢字と仮名の使い分け）
俳句：
AIに3句作らせる（先生用）
秋の俳句を3句作ってください。小学5年生が作ったような言葉で書いてください。
次のルーブリックの3つの観点を、それぞれA（よくできている）・B（できている）・C（もう少し）で評価したとき、次のようになる句を1つずつ作ってください。
・3つの観点すべてがAになる句（AAA）
・3つの観点すべてがBになる句（BBB）
・3つの観点すべてがCになる句（CCC）
3句の順番はばらばらにしてください。どの句がどの評価かは書かないでください。番号をつけて、句だけを並べてください。
ルーブリック
1　音数とリズム（五・七・五。字余り・字足らずは、あえてならOK）
2　季語（季節が伝わる言葉がひとつ。季重なりはおおらかに）
3　表現の工夫（比喩・反復・言葉の順序・漢字と仮名の使い分け）
「直した句は示さないでください」が足場です。完成形を見せられたら、子どもは写して終わります。直さないと決めるのも、立派な推敲です。

午前の授業③　4年 総合「柏木小のよいところを、青森の小学生に伝えよう」

共有ホワイトボードで、自分の番号の付箋を選ぶ → 書く前にまず付箋の色を変える（「使用中」の合図＝取り合い防止）→ よいところを付箋1枚に1つ → CanvaのAIで付箋を分類 → 「このまとまりでいいか」を話し合う → テーマを1つ選んでスライド1枚 → 近くの人に発表。

AIの分け方を正解にしません。「このまとまりの名前は合っている？」「この付箋はこっちじゃない？」と問い返します。学年一斉など人数が多いときは、ホワイトボードをクラスごとに分けると動きが軽くなります。
